# Технический долг

Сюда кладём временные решения («костыли»), которые мы осознанно оставили. Каждая запись — отдельный файл `YYYY-MM-DD-короткое-имя.md`.

В записи обязательно:

1. **Проблема** — что сломано и почему.
2. **Костыль** — что именно сделано и где (файлы, серверные настройки, значения без секретов).
3. **Чем плох** — риски и ограничения.
4. **Как откатить** — пошаговые команды.
5. **Как решить по-нормальному** — варианты и ориентир.
6. **Критерий закрытия** — когда запись можно удалить.

Секреты в записи не пишем: только имена переменных.
